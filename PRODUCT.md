# Ultra

Register: product.

Ultra helps instructors turn their source material into reviewed AI-led lectures. The studio serves an admin preparing and approving material; the separate classroom serves students watching and asking questions.

Existing product decisions: blue Ultra identity, sequential review gates, original slide preservation, autosaved work, global and local generation progress, optional grid or expandable rows for annotations, and a separate student experience without presenter notes.

Design direction: calm, clear and efficient. Prioritize the current task, visible progress, reversible edits and explicit next steps. Avoid marketing-style hero sections, competing primary actions, hidden prerequisites and exposing internal implementation details unnecessarily.

Implementation accessibility baseline: keyboard access, visible focus, meaningful labels, sufficient contrast, reduced motion, responsive layouts and status announcements. This is a design baseline, not a claim of formal accessibility certification.
